# 3DGS 近两年重大进展 (2024-2026)

> 整理日期：2026-05-18

---

## 原始工作回顾 (2023.08)

```
3D Gaussian Splatting for Real-Time Radiance Field Rendering (SIGGRAPH 2023)
  - 用各向异性 3D 高斯椭球表示场景
  - 可微分光栅化 → 端到端训练
  - 实时渲染 (>100 FPS) + 质量接近 NeRF
  - 训练速度快 (分钟级 vs NeRF 的小时级)
```

---

## 七、3DGS 地位变化总结

```
2023: "比 NeRF 快很多的新表示" (渲染工具)
2024: "通用 3D 表示" (扩展到动态/生成/SLAM/编辑)
2025-2026: "3D 世界的基础设施" (世界模型/仿真/交互)

核心优势:
  ✅ 实时渲染 (100+ FPS)
  ✅ 训练快 (分钟级)
  ✅ 显式表示 (可编辑/物理交互)
  ✅ 可微分 (端到端训练)

主要挑战:
  ❌ 大规模场景的内存消耗 (百万高斯)
  ❌ 几何精度不如 mesh (表面不连续)
  ❌ 动态场景的时间一致性
  ❌ 泛化能力 (逐场景优化 vs 通用模型)
```
