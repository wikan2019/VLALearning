## 4. 各模型深度分析

### RT-2-X — 先驱者（已过时）
*   **历史意义**：首个证明 VLM 知识可迁移到机器人的模型。
*   **当前地位**：已被 OpenVLA 等后续工作全面超越。
*   **主要问题**：55B 参数太大，闭源，推理极慢。

### Octo — 轻量级通用策略
*   **定位**：93M 参数的轻量级通用策略，面向学术研究。
*   **优势**：极小的模型，支持多机器人，开源友好。
*   **劣势**：没有 LLM 骨干，语言理解和推理能力弱。

### OpenVLA — 开源标杆
*   **定位**：VLA 领域的 "LLaMA"——开源、高效、人人可用。
*   **优势**：DINOv2+SigLIP 双编码器、LoRA 微调友好、消费级 GPU 可部署。
*   **劣势**：自回归 Binning 精度有限、逐步生成速度慢。

### OpenVLA-OFT — 优化后的王者
*   **定位**：OpenVLA 的增强版，通过四项优化达到接近完美的性能。
*   **优势**：LIBERO 97.1%、26x 吞吐量提升、超越 π0。
*   **劣势**：仅在仿真基准中验证，真实世界大规模部署待确认。

### π0 / π0.5 — 产业级通用基座
*   **定位**：最接近"通用机器人大脑"的模型。
*   **优势**：10000+ 小时数据、扩散策略精度高、双臂支持、开放世界泛化 (π0.5)。
*   **劣势**：未完全开源、训练数据不可复现、扩散推理慢。

### GR-2 — 视频生成路线
*   **定位**：ByteDance 的另一条路线——通过视频生成来做机器人控制。
*   **核心思想**：先生成"理想视频"（目标状态），再用逆动力学模型将视频转化为动作。
*   **优势**：可以利用互联网视频数据预训练。
*   **劣势**：视频生成质量和物理一致性仍是挑战。

## 11. VLA 的端到端控制与核心算法

### (a) 端到端控制确认

π0 系列（包括 π0.5、π0.6/π\*0.6、π0.7）的所有实用场景采用**完全端到端**控制：

```
[多视角相机图像] + [语言指令] + [关节状态]  →  🧠 单一 VLA 模型  →  [机器人关节动作]
```

**没有**传统的感知→规划→控制分立模块，没有手工编写的运动规划器（MPC/RRT）或逆运动学求解器。VLA 直接从原始像素输出关节级控制指令。

唯一的"分层"设计是 π0.5+ 的**高层-低层解耦**，但两层都在同一个神经网络内：
*   **高层**：VLM 骨干做语义规划（"把碗放到水槽"）
*   **低层**：动作专家头做运动控制（输出 Action Chunk）

### (b) 核心控制算法 1：Flow Matching（主力）

| 属性 | 细节 |
| :--- | :--- |
| **本质** | 广义扩散模型的改进版，基于 ODE（常微分方程）而非 SDE |
| **工作方式** | 从纯高斯噪声出发，**10 步迭代去噪**，沿近似直线路径生成高精度连续动作 |
| **训练目标** | 预测速度场 $v_\theta(x_t, t) \approx x_1 - x_0$（"该往哪走"） |
| **输出** | 一次生成未来 **16–50 步**的 Action Chunk（连续值，末端执行器 6DoF + 夹爪） |
| **优势** | 毫米级精度、天然支持多模态动作分布（不会取均值撞障碍物）、轨迹平滑 |
| **劣势** | 10 步去噪 ≈ 100ms，占推理总耗时 77%；无法利用 LLM 推理生态优化 |

### (c) 核心控制算法 2：FAST 自回归（高效变体）

| 属性 | 细节 |
| :--- | :--- |
| **本质** | 将动作轨迹做 **DCT（离散余弦变换）频域压缩**，再用 VQ 量化为 ~20 个离散 Token，由 VLM 自回归生成 |
| **压缩原理** | 机器人动作是时域平滑信号，低频系数捕获 >95% 能量，高频可截断。350 个原始值 → ~20 Token（17.5× 压缩） |
| **优势** | 比 Flow Matching **快 5 倍**；可直接使用 vLLM、KV Cache、TensorRT 等 LLM 推理优化 |
| **劣势** | 精度略低于 Flow Matching（但远高于 OpenVLA 的均匀 Binning） |

### (d) π0.6+ 的双轨方案

π0.6 及之后的模型**同时使用两种算法**，取长补短：

```
VLM 骨干 (SigLIP + Gemma3 4B)
    ↓ Hidden State
    ├── FAST Token (自回归，快)  ← 用于高频控制场景
    └── Flow Matching (扩散，精) ← 用于高精度灵巧操作
```

### (e) 训练阶段算法：Recap RL（π\*0.6）

Recap 不是推理时的控制算法，而是**训练阶段**的强化学习优化方法：

| 阶段 | 做法 |
| :--- | :--- |
| **Stage 1: 示教** | 在人类示教数据上监督学习（模仿） |
| **Stage 2: 纠错** | 专家在机器人犯错时实时接管纠正，收集纠错数据 |
| **Stage 3: 自主练习+RL** | 机器人自主练习，训练价值函数 $V(s)$，计算优势值 $A(s,a) = V(s') - V(s)$，用优势条件化策略训练——保留所有数据（好的和坏的），让模型学会区分并在部署时生成"高优势"动作 |

### (f) 算法对比总结

| 算法 | 用于 | 推理速度 | 精度 | 端到端 |
| :--- | :--- | :--- | :--- | :--- |
| **Flow Matching** | π0 全系列（主力） | ~130ms/chunk | 最高（毫米级） | ✅ |
| **FAST 自回归** | π0-FAST / π0.6+ | ~26ms/chunk | 高 | ✅ |
| **Recap RL** | π\*0.6 训练阶段 | N/A（训练用） | 提升成功率 40%→90%+ | ✅ |

## 12. 世界模型与强化学习在 VLA 中的作用

### (a) 世界模型的作用

当前主流 VLA（OpenVLA、π0）是**反应式**的：`观测→动作→执行`，没有"预演"过程。世界模型让 VLA 进化为**规划式**：

1.  **先在脑中预演** — 世界模型预测"如果执行动作 A，世界会变成什么样"，支持多步前瞻。
2.  **长程任务规划** — 复杂任务（如"清理整个厨房"）需要多步协调，反应式 VLA 做不到。
3.  **数据效率** — 在世界模型的"想象空间"中练习，减少真实世界数据依赖。
4.  **安全性** — 先在脑中试错，避免在真实世界中犯危险错误。

**代表范式**：**World-VLA-Loop**（2026 年最新）将世界模型和 VLA 闭环迭代优化——VLA 在世界模型中探索 → 世界模型提供奖励 → RL 优化 VLA → VLA 的失败又反馈改进世界模型。π0.7 也已引入轻量级世界模型来生成视觉子目标图像辅助规划。

| 特性 | 直接策略学习 (OpenVLA, π0) | 世界模型 + 规划 |
| :--- | :--- | :--- |
| **数据效率** | 需要大量演示 | 可以在虚拟中"想象"练习，数据更省 |
| **长程推理** | 弱（短视） | **强（可以预演多步）** |
| **推理速度** | 快 | 慢（需要生成视频/状态预测） |
| **成熟度** | 高（已有成功部署） | 低（仍在研究阶段） |
| **安全性** | 需要真实试错 | 可以在脑中试错，更安全 |

### (b) 强化学习的作用

纯模仿学习有两个根本瓶颈，RL 是解决方案：

**瓶颈 1：信用分配 (Credit Assignment)**

模仿学习只知道"最终失败了"，无法定位错误发生在哪一步；RL 通过价值函数追溯，精确识别出是哪个动作导致了后续失败。

```
Espresso 制作失败的场景:
  Step 3: 抓取滤杯 → 角度稍偏 (微小错误)
  Step 4: 搬运滤杯 → 看起来正常
  Step 5: 插入咖啡机 → 失败！滤杯卡住

  模仿学习: 只知道"最终失败了"，无法定位 Step 3 的角度错误
  强化学习: 通过价值函数追溯，识别出 Step 3 是问题根源
```

**瓶颈 2：超越示教数据质量**

模仿学习的上限是人类示教的质量；RL 可以从好的和坏的经验中都学习，训练出**比示教数据本身更优的策略**。

**最突出的案例是 π\*0.6 的 Recap 方法**：三阶段（示教→纠错→自主练习+RL）让 Espresso 制作从 ~40% 提升到 >90% 成功率，实现全天 18 小时连续运行。π0.7 更进一步将 Recap RL 的经验蒸馏到通用模型中，单模型匹配甚至超越多个专家。

### (c) 世界模型 × 强化学习的协同（前沿方向）

```
┌─────────────────────────────────────────────────────┐
│                  World-VLA-Loop                      │
│                                                     │
│  VLA 策略 ──→ 在虚拟环境中执行 ──→ 收集经验        │
│      ↑                                    ↓         │
│      │            ┌──────────────┐                  │
│      │            │ 视频世界模型  │ ← 从经验中学习   │
│      │            │ (预测未来)    │                  │
│      │            └──────┬───────┘                  │
│      │                   ↓                          │
│      └──── RL 优化 ←── 奖励信号                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

世界模型和 RL 在 VLA 中形成正反馈循环：世界模型提供"想象中的训练场"，RL 在其中高效优化策略；VLA 的失败又反过来帮助世界模型学习预测薄弱场景。这是 VLA 从"做简单任务"到"做复杂长程任务"的关键一步。
